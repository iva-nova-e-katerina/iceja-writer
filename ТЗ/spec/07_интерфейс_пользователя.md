# 7. Интерфейс пользователя

## 7.1. Главное окно

ИНТ-01. Главное окно (светлая тема, системный Look&Feel):

```
┌──────────────────────────────────────────────────────────────┐
│ Файл   Правка   Вид   Помощь                                  │
├────────────────┬─────────────────────────────────────────────┤
│ Дерево проекта │  Редактор: карточка сцены / текст сцены /     │
│  Описание      │  формы библии / панель «Черновик» LLM        │
│  Библия        │                                              │
│   Мир          │                                              │
│   Персонажи    │                                              │
│   Хронология   │                                              │
│   …            │                                              │
│  Акт 1         │                                              │
│   Глава 1      │                                              │
│    Сцена 1     │                                              │
├────────────────┴─────────────────────────────────────────────┤
│ Слов: 1 234 | Символов: 7 890 | Сохранено | Масштаб: 100%     │
└──────────────────────────────────────────────────────────────┘
```

ИНТ-02. Меню:

- **Файл**: Новый проект, Открыть, Недавние, Сохранить, Сохранить как, Экспорт в DOCX, Настройки, Выход.
- **Правка**: Отменить, Повторить, Найти/Заменить.
- **Вид**: Язык (Русский, English); Масштаб (75%, 100%, 125%, 150%, 200%, 300%).
- **Помощь**: Руководство, О программе, Удалить программу.

ИНТ-03. Статус-бар: число слов/символов текущей сцены (или проекта), индикатор сохранения, текущий масштаб, язык, состояние LLM-запроса (ожидание/прогресс/ошибка).

## 7.2. Локализация

| ID | Требование |
|---|---|
| ИНТ-10 | Два языка: русский и английский. Все строки UI, меню, диалоги, сообщения об ошибках — через ресурсы локализации (ResourceBundle `messages_*.properties`), без зашитых в код строк. |
| ИНТ-11 | Язык по умолчанию — язык локали ОС; переключение в «Вид → Язык» без перезапуска; выбор запоминается в настройках. |

## 7.3. Масштаб интерфейса (зум)

| ID | Требование |
|---|---|
| ИНТ-20 | Диапазон масштаба **75% – 300%**; пресеты 75/100/125/150/200/300% в меню «Вид → Масштаб». |
| ИНТ-21 | Масштаб применяется ко всему интерфейсу (главное окно и диалоги) через масштабирование шрифтов UIManager; состояние запоминается в настройках. |
| ИНТ-22 | По умолчанию — 100%. |

## 7.4. Клавиатура

| Сочетание | Действие |
|---|---|
| `Ctrl+N` | Новый проект |
| `Ctrl+O` | Открыть проект |
| `Ctrl+S` | Сохранить |
| `Ctrl+Shift+S` | Сохранить как |
| `Ctrl+F` | Поиск/замена |
| `Ctrl+Z` / `Ctrl+Y` | Отмена / повтор |
| `Ctrl+W` | Закрыть проект |

## 7.5. Удобство для писателя-непрофессионала

ИНТ-30. Все поля форм имеют всплывающие подсказки (tooltips) с объяснением назначения (например, «Цель сцены: чего должен достичь герой в этой сцене»).

ИНТ-31. Сообщения об ошибках — на языке пользователя, с объяснением, что делать дальше (а не кодом исключения).

ИНТ-32. Мастер создания проекта — не более 3 шагов.

ИНТ-33. Меню «Помощь → Руководство» открывает Руководство пользователя на русском языке.

## 7.6. Диалоги

| Диалог | Ссылка на требования |

## 7.7. Состояния LLM-операций в UI

ИНТ-40. Длительные LLM-операции (генерация, проверки) отображают: индикатор прогресса, кнопку «Отмена», сообщение о результате или ошибке. Основное окно остаётся доступным для работы.
