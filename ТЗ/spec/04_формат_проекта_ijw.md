# 4. Формат файла проекта `.ijw`

## 4.1. Общие требования

ФРМ-01. Файл проекта имеет расширение `.ijw` и представляет собой ZIP-архив (метод DEFLATE), содержащий только текстовые файлы в кодировке UTF-8 (JSON и Markdown). Архив открывается и редактируется любым ZIP-архиватором.

ФРМ-02. Формат версионируется: `manifest.json.formatVersion`. Приложение читает все форматы с номером, не большим поддерживаемого; при открытии более нового формата выводит понятную ошибку с указанием версии.

ФРМ-03. Все строковые данные — UTF-8; переводы строк в Markdown — `\n` (LF).

## 4.2. Структура архива

```
project.ijw
├── manifest.json            — метаданные проекта
├── novel.json               — описание романа (сюжет), ≤ 2 КБ
├── bible/
│   ├── world.json           — мир
│   ├── characters.json      — персонажи
│   ├── chronology.json      — хронология
│   ├── rules.json           — правила
│   ├── storylines.json      — сюжетные линии
│   ├── glossary.json        — глоссарий
│   └── style.json           — стиль
└── scenes/
    ├── scene-0001.json      — карточка сцены 1
    ├── scene-0001.md        — текст сцены 1
    ├── scene-0002.json
    ├── scene-0002.md
    └── …
```

ФРМ-04. Нумерация сцен сквозная: `scene-0001`, `scene-0002`, … (до 9999). Имя файла карточки и текста совпадает.

## 4.3. manifest.json

```json
{
  "formatVersion": 1,
  "appVersion": "0.1.0",
  "title": "Название романа",
  "createdAt": "2026-09-18T10:00:00Z",
  "updatedAt": "2026-09-18T10:00:00Z"
}
```

## 4.4. novel.json — описание романа

```json
{
  "title": "Название романа",
  "author": "Имя автора",
  "logline": "Одна фраза о сути романа",
  "theme": "Главная тема",
  "plot": "Описание сюжета (произвольный текст)"
}
```

ФРМ-05. **Ограничение 2 КБ:** суммарный размер файла `novel.json` в UTF-8 (байты) не должен превышать **2048 байт**. Редактор показывает счётчик «N / 2048 байт» и блокирует сохранение при превышении лимита.

## 4.5. bible/ — Библия романа (семь разделов)

ФРМ-06. `bible/world.json` — мир:

```json
{
  "geography": "", "politics": "", "economy": "",
  "techMagic": "", "religion": "", "languages": "", "notes": ""
}
```

ФРМ-07. `bible/characters.json` — массив карточек персонажей:

```json
[
  {
    "id": "char-001",
    "name": "Имя",
    "aliases": [],
    "role": "Роль в сюжете",
    "ageByYear": {"1918": 25, "1945": 52},
    "arcs": ["Описание арки"],
    "relationships": [{"withId": "char-002", "type": "Соперник", "notes": ""}],
    "voice": "Особенности речи",
    "knows": ["Что знает"],
    "doesNotKnow": ["Чего не знает"],
    "traumas": [], "goals": [], "weakness": "", "notes": ""
  }
]
```

ФРМ-08. `bible/chronology.json` — массив событий хронологии: `{"date": "1905-01", "event": "", "notes": ""}`. В интерфейсе события сортируются по дате.

ФРМ-09. `bible/rules.json` — правила мира: `{"possible": "", "impossible": "", "cost": "", "limits": "", "notes": ""}`.

ФРМ-10. `bible/storylines.json` — сюжетные линии A/B/C:

```json
[
  {"id": "A", "name": "", "setup": "", "secrets": [], "foreshadowing": [], "resolution": "", "notes": ""}
]
```

ФРМ-11. `bible/glossary.json` — массив терминов: `{"term": "", "definition": ""}`.

ФРМ-12. `bible/style.json` — стиль: `{"pov": "", "tense": "", "tone": "", "forbiddenWords": [], "typicalPhrases": [], "notes": ""}`.

## 4.6. scenes/ — карточки и тексты сцен

ФРМ-13. Карточка сцены `scene-NNNN.json` (поля по методологии `концепт.docx`):

```json
{
  "id": "scene-0001",
  "number": 1,
  "act": 1,
  "chapter": 1,
  "title": "",
  "status": "draft",
  "pov": "char-001",
  "location": "",
  "time": "",
  "goal": "",
  "conflict": "",
  "twist": "",
  "readerLearns": "",
  "charactersLearn": "",
  "entry": "",
  "exit": "",
  "continuityNotes": [],
  "summary": "",
  "wordTargetMin": 800,
  "wordTargetMax": 1500,
  "wordCount": 0,
  "updatedAt": "2026-09-18T10:00:00Z"
}
```

- `status` — одно из: `draft` (черновик), `revised` (правится), `approved` (утверждена).
- `pov` — идентификатор персонажа из библии (пустая строка — не задан).
- `summary` — резюме сцены, заполняется после утверждения (используется как «резюме предыдущей сцены» при генерации следующей).

ФРМ-14. Текст сцены `scene-NNNN.md` — Markdown (обычный текст). В тексте допустимы служебные пометки новых фактов `[NEW]`; при экспорте они удаляются (см. ФР-92).

## 4.7. Целостность ссылок и валидация

ФРМ-20. При открытии выполняется валидация: наличие `manifest.json`, разбор всех JSON, уникальность `id`, существование ссылок `relationships.withId` и `pov` на персонажей библии, парность `scene-NNNN.json`/`scene-NNNN.md`.

ФРМ-21. Нарушения валидации не должны приводить к потере данных: повреждённые элементы показываются в отчёте «Проверка проекта» с указанием файла и проблемы.

ФРМ-22. Повреждённый (нечитаемый) архив: понятное сообщение + предложение восстановить проект из последней резервной копии (`.ijw.bak-N`).

## 4.8. Запись, атомарность, резервные копии

ФРМ-30. Сохранение атомарно: запись во временный файл рядом с проектом → переименование поверх `.ijw`.

ФРМ-31. Перед каждой перезаписью создаётся резервная копия с ротацией: `project.ijw.bak-1` (последняя), `project.ijw.bak-2`, … Количество копий настраивается в «Настройках» (0–9, по умолчанию 3).

ФРМ-32. Одновременное открытие одного `.ijw` вторым экземпляром приложения — предупреждение и отказ от записи (файл-блокировка `.lock` с PID).

## 4.9. Ограничения объёма

| Параметр | Ограничение |
|---|---|
| Роман целиком | до 600 страниц ≈ 150 000 слов (расчётное) |
| Описание романа (`novel.json`) | ≤ 2048 байт (2 КБ) |
| Сцен | 1–9999 |
| Один файл текста сцены | без жёсткого лимита |
| Символы в тексте | UTF-8 без ограничений |
