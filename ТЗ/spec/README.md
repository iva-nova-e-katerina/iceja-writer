Комплект спецификаций на программное обеспечение **IceJA Writer** для упрощения написания художественных произведений (романы объёмом до 600 страниц).

## Ключевые решения, зафиксированные в комплекте

1. **Без СУБД.** Все данные хранятся в текстовых файлах (JSON/Markdown, UTF-8) внутри ZIP-файла проекта `.ijw`; настроечные данные — в `config/app.json`. Сторонние инструменты (Obsidian, Scrivener, RAG и т. п.) не устанавливаются приложением; обеспечивается только совместимость форматов.
2. **Единый portable JAR.** Один файл `iceja-writer.jar` содержит приложение, установщик и деинсталлятор; зависит только от JRE 25 (LTS) и более новых версий.
3. **LLM-провайдеры:** OpenAI, Anthropic и «Свой провайдер» (OpenAI-совместимый API). Название модели пользователь **обязательно** выбирает из списка, загруженного у провайдера, — ручной ввод названия не предусмотрен.
4. **Экспорт готового романа в Word (.docx)** — обязательная функция (ФР-90…ФР-95).
5. **Бесплатная, лицензия MIT** (файл `LICENSE` в корне репозитория) — свободное использование, изменение и распространение, в том числе коммерческое.
6. Язык комплекта документов — русский.
