# 5. Функциональные требования

## 5.1. Управление проектом

| ID | Требование |
|---|---|
| ФР-01 | Создание проекта: мастер (название романа, автор, каталог). Создаёт `.ijw` с пустыми структурами по разделу 4. |
| ФР-02 | Открытие проекта: выбор файла `.ijw`; список недавних проектов (до 10) в меню «Файл → Недавние». |
| ФР-03 | Сохранение: `Ctrl+S`; «Сохранить как» (`Ctrl+Shift+S`); признак несохранённых изменений — `*` в заголовке окна. |
| ФР-04 | Закрытие проекта / выход из приложения с запросом о несохранённых изменениях (Сохранить / Не сохранять / Отмена). |

## 5.2. Навигатор проекта

| ID | Требование |
|---|---|
| ФР-10 | Дерево проекта: Описание → Библия (Мир, Персонажи, Хронология, Правила, Сюжетные линии, Глоссарий, Стиль) → Акт 1 (Глава 1 (Сцена 1 …)) … |
| ФР-11 | Перестановка сцен перетаскиванием (drag&drop) между главами; сквозная перенумерация после перемещения. |
| ФР-12 | Контекстные операции: добавить сцену/главу/акт, дублировать сцену, удалить (с подтверждением). Удаление сцены удаляет карточку и текст. |

## 5.3. Описание романа

| ID | Требование |
|---|---|
| ФР-20 | Редактор полей `novel.json` (название, автор, логлайн, тема, сюжет). |
| ФР-21 | Индикатор «N / 2048 байт» для `novel.json`; блокировка сохранения при превышении 2 КБ с пояснением. |

## 5.4. Редакторы Библии романа

| ID | Требование |
|---|---|
| ФР-30 | Мир, Правила, Стиль — редакторы многострочных полей соответствующих JSON-файлов. |
| ФР-31 | Персонажи — список карточек слева, редактор полей карточки справа (все поля ФРМ-07); выбор связанных персонажей из существующих. |
| ФР-32 | Хронология — таблица «Дата / Событие / Примечания», сортировка по дате, добавление/правка/удаление. |
| ФР-33 | Сюжетные линии — список линий A/B/C с редактором (завязка, тайны, предзнаменования, развязка). |
| ФР-34 | Глоссарий — таблица «Термин / Определение», сортировка по алфавиту. |
| ФР-35 | Поиск по всем разделам библии с переходом к найденному элементу. |

## 5.5. Карточки сцен

| ID | Требование |
|---|---|
| ФР-40 | Редактор карточки сцены: все поля ФРМ-13; POV выбирается из списка персонажей библии; акт/глава — числовые поля; статус — выпадающий список. |
| ФР-41 | Переключение «Карточка / Текст» для выбранной сцены; обе вкладки редактируемы. |

## 5.6. Текст сцены

| ID | Требование |
|---|---|
| ФР-50 | Редактор текста сцены (Markdown): перенос строк, отмена/повтор (`Ctrl+Z`/`Ctrl+Y`), поиск/замена (`Ctrl+F`). |
| ФР-51 | Подсветка пометок `[NEW]` в тексте цветом. |
| ФР-52 | В статус-баре: число слов/символов сцены и соответствие `wordTargetMin/Max` (визуальная индикация «меньше нормы / в норме / больше нормы»). |

## 5.7. Структура и планирование

| ID | Требование |
|---|---|
| ФР-60 | Акт и глава — атрибуты сцены; сквозная нумерация сцен ведётся автоматически. |
| ФР-61 | Перспектива (вне первой версии): уровни «цикл → арка серии → роман → акт → глава → сцена → бит» из методологии. |

## 5.8. Поиск и статистика

| ID | Требование |
|---|---|
| ФР-70 | Полнотекстовый поиск по текстам сцен и библии; список результатов; двойной клик открывает место в редакторе. |
| ФР-71 | Сводная статистика: всего слов/сцен/глав, объём по актам, прогресс утверждения сцен (черновик/правится/утверждена). |

## 5.9. Автосохранение

| ID | Требование |
|---|---|
| ФР-80 | Автосохранение с настраиваемым интервалом (по умолчанию 5 минут; 1–60 мин или выключено). |
| ФР-81 | Дополнительно автосохранение при переключении сцены и при закрытии проекта (перед запросом о сохранении). |

## 5.10. Экспорт романа в Word (.docx)

| ID | Требование |
|---|---|
| ФР-90 | Команда «Экспорт в DOCX» в меню «Файл». |
| ФР-91 | Сборка документа: опциональная титульная страница (название, автор); далее сцены в порядке сквозной нумерации; заголовки: акт — стиль «Заголовок 1», глава — «Заголовок 2»; тексты сцен — обычным текстом. |
| ФР-92 | Диалог экспорта с опциями: 1) включить титульную страницу (да/нет); 2) фильтр сцен по статусу (все / только утверждённые); 3) разделитель между сценами (нет / пустая строка / символ «⁂»); 4) удалять служебные пометки `[NEW]` из текста (по умолчанию — да). |
| ФР-93 | Имя файла по умолчанию «Название романа.docx» рядом с `.ijw`; выбор каталога; сообщение об успехе с кнопкой «Открыть каталог». |
| ФР-94 | Реализация — собственный генератор OOXML (Office Open XML) без внешних программ: DOCX не требует установленного Microsoft Word. Если применяется сторонняя библиотека генерации DOCX, она упаковывается в тот же JAR (не нарушая АРХ-01). |
| ФР-95 | Приёмка экспорта: файл открывается в LibreOffice Writer и Microsoft Word без ошибок; порядок сцен и заголовки корректны; русский и английский текст без искажения кодировки; объём текста соответствует проекту. |

## 5.11. Настройки приложения

| ID | Требование |
|---|---|
| ФР-100 | Диалог «Настройки» (меню «Файл → Настройки»): вкладки «Общие» и «LLM». |
| ФР-101 | Вкладка «Общие»: язык интерфейса (Русский/English), масштаб по умолчанию (75–300%), интервал автосохранения, каталог проектов по умолчанию, число резервных копий (0–9). |
| ФР-102 | Вкладка «LLM» — по документу 06 (LLM-01…LLM-05). |

## 5.12. Справка

| ID | Требование |
|---|---|
| ФР-110 | Меню «Помощь → Руководство» открывает Руководство пользователя (UserManual, русский язык). |
| ФР-111 | Меню «Помощь → О программе»: версия, лицензия (MIT — бесплатное распространение), дисклеймер об использовании AI при написании текста. |
