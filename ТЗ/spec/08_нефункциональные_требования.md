# 8. Нефункциональные требования

| ID | Требование |
|---|---|
| НФР-01 | **Производительность.** Открытие проекта объёмом 150 000 слов (600 страниц) — не более 5 секунд на SSD. Ввод текста — без заметных задержек. Поиск по проекту — результат не более 2 секунд. |
| НФР-02 | **Отзывчивость.** LLM-запросы выполняются асинхронно и не блокируют интерфейс (ИНТ-40). |
| НФР-03 | **Надёжность.** Автосохранение (ФР-80/ФР-81), атомарная запись (ФРМ-30), ротация резервных копий (ФРМ-31), восстановление из резервной копии (ФРМ-22). Сбой при сохранении не должен уничтожать существующий `.ijw`. |
| НФР-04 | **Журналирование.** `logs/app.log` с ротацией; журнал не содержит API-ключей и содержимого промптов. |
| НФР-05 | **Безопасность ключа.** API-ключ хранится только в `config/app.json` с правами 600 (POSIX); не попадает в `.ijw`, резервные копии, журналы и диалоги экспорта; в UI маскируется. |
| НФР-06 | **Совместимость.** JRE 25+ (LTS). ОС: Linux (основная), Windows, macOS (x64/arm64 по возможности). Все файлы — UTF-8; при запуске на Linux/Windows русский и английский текст отображается без искажений. |
| НФР-07 | **Портативность.** Один JAR (АРХ-01); запуск без установки; полное удаление — удалением каталога (АРХ-05); переносимость установки копированием каталога. |
| НФР-08 | **Минимум зависимостей.** Без СУБД, без нативных библиотек, без внешних сервисов; список зависимостей по АРХ-03. |
| НФР-09 | **Масштаб.** До 600 страниц / 150 000 слов / 10 000 сцен на проект. |
| НФР-10 | **Доступность.** Руководство пользователя на русском; интерфейс доступен с клавиатуры; масштаб до 300% для слабого зрения. |
| НФР-11 | **Офлайн-работа.** Редактирование, сохранение, экспорт DOCX работают без сети; сеть требуется только для LLM-операций. |
| НФР-12 | **Тестирование.** Обязательные автотесты: валидатор `.ijw` (структура, ссылки), лимит 2 КБ описания, атомарная запись и ротация резервных копий, сборка курированного контекста и промптов, парсер списка моделей (mock), генератор DOCX (структура OOXML), локализация (полнота ключей RU/EN). Приёмочные прогоны: smoke-тест GUI (xvfb), ручное тестирование установки/деинсталляции на чистых системах. Критерий: все необходимые тесты проходят. |
| НФР-13 | **Обратная совместимость формата.** Приложение открывает проекты всех предыдущих версий `formatVersion` (ФРМ-02). |
| НФР-14 | **Юридические примечания.** Дисклеймер о правах на AI-текст в «О программе» (ФР-111) и в Руководстве. |
