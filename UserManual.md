Руководство по работе с программой **IceJA Writer** — инструментом для написания художественных романов (до 600 страниц) вместе с языковой моделью (LLM).

>
> **Язык документа:** русский.

## 1. Что такое IceJA Writer

IceJA Writer — настольная программа для писателей. Она помогает вести **весь материал романа в одном месте**:

- описание романа (сюжет);
- «Библию романа» — мир, персонажи, хронологию, правила, сюжетные линии, глоссарий и стиль;
- карточки сцен — планы каждой сцены;
- сами тексты сцен.

Кроме того, программа умеет обращаться к языковой модели (LLM) — писать **черновики сцен по вашим карточкам**, предлагать варианты, проверять текст на противоречия — и собирать готовый роман в файл **Word (.docx)**.

Программа **бесплатная** и распространяется по лицензии **MIT** (полный текст — файл `LICENSE` в поставке).

Программа **переносимая**: один файл, простая установка, простое удаление. Никаких баз данных и фоновых служб — все данные хранятся в обычных текстовых файлах.

## 2. Главная идея: вы — шоураннер

Попросить нейросеть «написать роман целиком» нельзя: она не помнит ваш мир, персонажей и хронологию. Поэтому IceJA Writer построен по принципу **фабрики текста**:

- **Вы** — автор, архитектор и редактор. Вы решаете, что является каноном вашего романа.
- **Нейросеть** — очень быстрый, но забывчивый помощник, который пишет черновики.

Порядок работы:

1. Вы ведёте **Библию романа** — все факты о мире, персонажах, правилах.
2. Для каждой сцены вы заполняете **карточку сцены** — маленький план: кто, где, зачем, что происходит.
3. Программа собирает контекст (срез библии + карточка + резюме предыдущей сцены) и просит модель **написать черновик сцены** (800–1500 слов).
4. Вы правите черновик или просите альтернативы.
5. Модель выдаёт **протокол изменений**: какие новые факты появились, какие возникли вопросы и противоречия. Вы решаете, что внести в библию.
6. Только после этого вы переходите к следующей сцене.

Главное правило: **ни один новый факт не попадает в библию без вашего утверждения**.

## 3. Что нужно для работы

1. **Java Runtime Environment (JRE) версии 25 или новее.** Программа не устанавливает Java сама. Скачать её можно, например, с сайта [Adoptium Temurin](https://adoptium.net/) (бесплатно). Если Java не установлена, программа сама сообщит об этом при запуске.
2. **API-ключ LLM-провайдера** (для функций генерации). Поддерживаются OpenAI, Anthropic и другие провайдеры с OpenAI-совместимым API (например, DeepSeek). Без ключа программа полностью работает как органайзер и редактор — но без генерации текстов.
3. ОС Linux, Windows или macOS. Интернет нужен только для LLM-функций.

## 4. Установка

1. Положите файл `iceja-writer.jar` в удобное место.
2. Запустите мастер установки:
   - в проводнике: двойной клик по файлу (если Java настроена на открытие `.jar`);
   - или в терминале: `java -jar iceja-writer.jar --install`.
3. В мастере (3–4 простых шага):
   - подтвердите лицензию (MIT — программа бесплатна);
   - выберите каталог установки (по умолчанию предлагается папка рядом с JAR);
   - нажмите «Установить»;
   - по желанию — «Запустить IceJA Writer».

После установки в выбранном каталоге появится всё необходимое:

```
IceJAWriter/
├── iceja-writer.jar      — программа
├── iceja-writer.sh/bat   — скрипты запуска
├── config/app.json       — ваши настройки
├── projects/             — папка проектов по умолчанию
└── logs/                 — журналы
```

Дальше запускать программу можно двойным кликом по `iceja-writer.jar` или через скрипт запуска.

> Программа переносима: весь каталог можно скопировать на другой компьютер (с установленной Java 25+) — и всё будет работать.

## 5. Первый запуск: язык и масштаб

- **Язык.** Программа говорит по-русски и по-английски. По умолчанию берётся язык вашей системы. Переключить: **Вид → Язык → Русский / English**. Выбор запоминается.
- **Масштаб.** Весь интерфейс можно увеличить или уменьшить от **75% до 300%** (полезно при слабом зрении или мелком экране): **Вид → Масштаб →** выберите процент. По умолчанию — 100%.

## 6. Создание проекта

**Файл → Новый проект** (или `Ctrl+N`). В мастере укажите:

1. название романа;
2. имя автора;
3. каталог, где будет лежать файл проекта.

Программа создаст **файл проекта с расширением `.ijw`** — это ZIP-архив с текстовыми файлами:

```
МойРоман.ijw
├── novel.json          — описание романа (сюжет)
├── bible/              — библия (мир, персонажи, хронология и т. д.)
└── scenes/             — карточки и тексты сцен
```

Вся работа над романом хранится в этом одном файле. Его легко копировать, пересылать и хранить в резерве.

## 7. Окно программы

Слева — **дерево проекта**:

- **Описание** — сюжет романа;
- **Библия** — семь разделов: Мир, Персонажи, Хронология, Правила, Сюжетные линии, Глоссарий, Стиль;
- **Акты → Главы → Сцены** — структура романа.

Справа — **редактор**: карточка сцены или текст сцены, формы библии, черновики от нейросети.

Внизу — **статус-бар**: счётчик слов/символов, индикатор сохранения, масштаб, состояние запроса к нейросети.

## 8. Описание романа

Раздел **Описание** содержит: название, автора, логлайн (суть романа в одной фразе), тему и сам **сюжет**.

Ограничение: описание романа не должно превышать **2 КБ** (2048 байт) — редактор показывает счётчик «N / 2048 байт» и не даст сохранить, если лимит превышен. Это осознанное требование: сюжет — краткая выжимка, подробности живут в библии и карточках сцен.

## 9. Библия романа

Библия — рабочая база **канона**: всё, что модель (и вы) должны помнить о мире. Семь разделов:

| Раздел | Что хранит |
|---|---|
| **Мир** | География, политика, экономика, технологии/магия, религия, языки |
| **Персонажи** | Карточки персонажей: роль, возраст по годам, арки, отношения, голос, что знает/чего не знает, травмы, цели, слабости |
| **Хронология** | События с датами (например: `1888-09 — героиня приезжает в город`) |
| **Правила** | Что возможно в вашем мире, что невозможно, цена и ограничения |
| **Сюжетные линии** | Линии A/B/C: завязки, тайны, предзнаменования, развязки |
| **Глоссарий** | Термины и определения, сортировка по алфавиту |
| **Стиль** | POV, время повествования, тон, запрещённые слова, типичные обороты |

Заполняйте библию по ходу работы и **обязательно обновляйте** после каждой сцены, когда появляются новые факты (см. «Протокол изменений»). Чем точнее библия, тем лучше черновики.

## 10. Карточки сцен

Карточка сцены — маленький план перед написанием текста. Поля:

| Поле | Вопрос, на который отвечает |
|---|---|
| Акт, глава | Где сцена в структуре романа |
| POV | От чьего лица рассказ (выбирается из персонажей библии) |
| Место, время | Где и когда происходит сцена |
| Цель | Чего должен достичь герой в этой сцене |
| Конфликт | Что мешает |
| Поворот | Что неожиданно меняется |
| Что узнаёт читатель | Новая информация для читателя |
| Что узнают герои | Новая информация для персонажей |
| Вход / Выход | С чего сцена начинается и чем заканчивается |
| Continuity notes | Кто где, что у кого, кто что знает на начало сцены |
| Статус | Черновик → Правится → Утверждена |
| Целевой объём | Рекомендуемое число слов (по умолчанию 800–1500) |

Совет из методологии: не просите нейросеть «написать главу 12». Просите «написать сцену 7 главы 12 по карточке» — с карточкой результат будет предсказуемым.

## 11. Написание текста

Вкладка **«Текст»** сцены — обычный текстовый редактор с переносом строк:

- отмена/повтор — `Ctrl+Z` / `Ctrl+Y`;
- поиск и замена — `Ctrl+F`;
- статус-бар показывает число слов и символов сцены и подсказывает, попадаете ли вы в целевой объём (800–1500 слов по умолчанию).

Пометки **[NEW]** в тексте подсвечиваются — так видно, какие новые факты предложила модель (подробнее — в «Протоколе изменений»). При экспорте в Word пометки автоматически убираются.

## 12. Подключение LLM

Чтобы использовать генерацию текста, настройте подключение к языковой модели:

**Файл → Настройки → вкладка «LLM»**.

1. **Провайдер** — выберите один из трёх:
   - **OpenAI**;
   - **Anthropic**;
   - **Свой провайдер** — любой сервис с OpenAI-совместимым API (например, DeepSeek). Укажите его адрес, например `https://api.deepseek.com/v1`.
2. **API-ключ** — вставьте ключ, полученный в личном кабинете провайдера. Вводится скрыто, есть кнопка «показать/скрыть». Ключ хранится в настройках программы и **не попадает** в файл проекта `.ijw` и в журналы.
3. Нажмите **«Загрузить список моделей»** — программа сама запросит у провайдера актуальный список моделей, и вы выберете модель из него. **Вводить название модели вручную не нужно** — только выбор из списка.
4. Нажмите **«Проверить соединение»** — программа сделает контрольный запрос и покажет результат.

Если список моделей не загружается — проверьте ключ, адрес провайдера и подключение к интернету: программа подскажет причину.

Там же задаются параметры генерации: **температура** (степень «творческой свободы» модели), **максимальное число токенов**, **таймаут**.

## 13. Генерация черновика сцены

1. Выберите сцену в дереве, заполните её карточку.
2. Нажмите **«Сгенерировать черновик»**.
3. Программа соберёт **контекст** (не весь роман, а нужное: срез библии, стиль, резюме предыдущей сцены, вашу карточку) и отправит модели.
4. Пока идёт генерация, можно продолжать работать — запрос выполняется в фоне. Есть кнопка «Отмена».
5. Результат появится в панели **«Черновик»** — он **не записывается в сцену сам**:
   - **«Принять»** — черновик становится текстом сцены;
   - **«Править вручную»** — перенос в редактор для правки;
   - **«Запросить альтернативу»** — другой вариант;
   - **«Отклонить»** — выбросить.

Новые важные факты, которые модель придумала сама, она помечает **[NEW]** — чтобы вы их сразу видели и решали их судьбу.

## 14. Протокол изменений

Вместе с черновиком модель выдаёт **протокол изменений** — список:

- **новые факты** (что появилось впервые);
- **изменения состояния** (что изменилось у героев/мира);
- **открытые вопросы** (что требует вашего решения);
- **возможные противоречия** (что конфликтует с библией).

Просмотрите протокол и решите, что делать с каждым пунктом. Кнопка **«Добавить в библию»** позволяет внести выбранные факты в нужный раздел (персонажи, хронология, правила и т. д.) — но **только после вашего явного подтверждения**. Ничего не попадает в канон само.

## 15. Альтернативные варианты

Если черновик не нравится — **«Запросить альтернативу»**. Модель напишет до трёх вариантов; каждый сопровождается собственным протоколом изменений. Сравнивайте и принимайте лучший.

## 16. Проверки текста

После главы или акта запускайте проверки (в разработке): **меню «Помощь» или кнопка «Проверки»**. Выберите тип:

- **continuity** — не противоречит ли текст библии;
- **логика** — причины, следствия, мотивация;
- **хронология** — даты, расстояния, возраст;
- **знание персонажей** — кто что может знать;
- **стиль** — POV, время, голос, анахронизмы;
- **сюжетные дыры** — забытые ружья, неразрешённые тайны.

Модель выступает «редактором-континуистом»: она **только перечисляет проблемы** (с указанием сцен), ничего не переписывая. Двойной клик по пункту открывает нужную сцену. Финальное решение — всегда за вами.

## 17. Резюме сцен

После того как сцена утверждена, программа может сгенерировать её **резюме** (2–5 предложений) и сохранить в карточке. Это не украшение, а рабочий механизм: при генерации следующей сцены программа подставляет резюме предыдущей, чтобы модель помнила, где остановилось повествование.

## 18. Экспорт романа в Word

Готовый роман выгружается в **Microsoft Word (.docx)**:

**Файл → Экспорт в DOCX**.

В диалоге можно выбрать:

- **титульная страница** — да/нет (название и автор);
- **какие сцены** — все или только утверждённые;
- **разделитель между сценами** — нет / пустая строка / символ «⁂»;
- **убрать пометки [NEW]** — по умолчанию да (они служебные).

Программа собирает сцены в порядке нумерации: заголовки актов и глав — стилями «Заголовок», тексты — обычным текстом. Файл `НазваниеРомана.docx` создаётся рядом с проектом и открывается в **Word или бесплатном LibreOffice Writer**. Сама программа Word для экспорта не требуется.

## 19. Сохранение и резервные копии

- **Сохранить** — `Ctrl+S`; «Сохранить как» — `Ctrl+Shift+S`.
- **Автосохранение** — по умолчанию каждые 5 минут (настраивается в «Настройках»); также программа сохраняет проект при переключении сцены и при закрытии.
- **Резервные копии** — перед каждой перезаписью проекта создаётся копия `МойРоман.ijw.bak-1`, `.bak-2`… (сколько хранить — настраивается, по умолчанию 3). Если файл проекта повредился, программа сама предложит восстановить его из последней копии.
- Несохранённые изменения отмечены звёздочкой `*` в заголовке окна.

## 20. Поиск и статистика

- **Поиск** — `Ctrl+F` по тексту; поиск по всему проекту (тексты сцен и библия) с переходом к результатам.
- **Статистика** — сводка: всего слов, сцен, глав; объём по актам; сколько сцен в черновиках, правке и утверждено.

## 21. Обновление и удаление программы

- **Обновление.** Скачайте новый `iceja-writer.jar` и запустите установку в тот же каталог — программа обновится, а ваши проекты и настройки сохранятся.
- **Удаление.** Запустите `java -jar iceja-writer.jar --uninstall` (или меню «Помощь → Удалить программу»). Программа предупредит, если в каталоге установки есть проекты `.ijw`, и после подтверждения удалит всё. Следов в системе не остаётся — программа не трогает реестр, службы и автозагрузку.

## 22. Частые вопросы

**Программа не запускается.** Проверьте, что установлена Java 25 или новее (команда `java -version`). Если Java нет — скачайте Temurin с adoptium.net и установите.

**Список моделей не загружается.** Проверьте API-ключ, адрес провайдера и интернет-соединение. Поле «Модель» останется неактивным, пока список не загрузится, — вводить название вручную нельзя, это защита от опечаток.

**Мой ключ куда-нибудь утечёт?** Ключ хранится только в файле настроек программы (`config/app.json`). В файл проекта `.ijw`, резервные копии и журналы он не попадает.

**Можно ли работать без интернета?** Да. Редактирование, сохранение и экспорт в Word работают полностью офлайн; интернет нужен только для генерации текста и проверок.

**Могу ли я открыть проект без программы?** Да. Файл `.ijw` — это обычный ZIP-архив: внутри человекочитаемые JSON и Markdown. Тексты сцен совместимы с Obsidian и другими редакторами Markdown.

**Перенесу ли я проект на другой компьютер?** Скопируйте файл `.ijw` — это весь проект. Программа переносима и не привязывает данные к машине.

**Программа платная?** Нет, IceJA Writer бесплатна и распространяется по лицензии MIT: её можно свободно использовать, копировать, изменять и распространять — в том числе в коммерческих целях — при условии сохранения уведомления об авторских правах. Полный текст лицензии — файл `LICENSE`.
